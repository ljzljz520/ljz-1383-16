# 证书证据管理验收用例

以下用例覆盖事件身份、状态计算、并发、图片、来源、时区和下游传播。测试环境必须能构造固定的服务器权威时间。

## 1. 补发图片不新增成就

**前置**：证书 C1 已存在，状态有效，成就计数 1。

1. 上传同一证书的新原件 `certificate-v2.jpg`。
2. 派生服务生成新脱敏图。
3. 记录 `asset.uploaded` 与 `asset.replaced`。

**预期**：

- `certificates.certificate_id` 不变。
- `achievement_count = 1`。
- 新文件出现在资产版本链，旧文件仍可审计。
- 公开页只显示当前公开派生图，不出现原件 URL。

## 2. 续期不新增成就

1. 对 C1 调用续期 API，新区间为 `2027-03-16` 至 `2029-03-15 Asia/Shanghai`。
2. 管理 API 重试同一 `Idempotency-Key`。

**预期**：只有一条 `certificate.renewed`；新事件进入时间线；成就计数保持 1；到期后实时计算为过期。

## 3. 新获奖才新增成就

1. 录入不同编号、不同证书类型的 C2。
2. 再录入仅有奖项名称相同但签发方和获奖年度不同的 C3。

**预期**：C2、C3 是不同身份；若同一签发方 + 类型 + 规范编号相同，则拒绝重复创建并指向既有身份；匹配依据不足时进入复核。

## 4. 图片处理失败

1. 上传原件，OCR 成功但脱敏服务超时。
2. 打开公开页。
3. 后台重试成功。

**预期**：

- 失败时状态为 `derivation_failed`，公开页显示“图片处理失败，仅展示文字证据”。
- 任意响应均无私密原件 URL。
- 重试成功后只更新公开派生资产，不新增证书或成就。

## 5. 续期与撤回并发

1. 两个事务同时对 C1 提交续期和撤销，撤销 `effective_at` 早于续期区间开始。
2. 两事务使用不同幂等键。

**预期**：

- 证书行串行化，两个事件最终都保留。
- 当前状态为 `revoked`。
- 续期区间作为历史可查询，但被撤销点覆盖。
- 技能证据与简历候选收到撤销投影；冻结简历不被修改。
- 若版本冲突无法自动归并，返回 409 而不是丢事件。

## 6. 追溯撤销迟到

1. C1 在 9 月仍显示有效。
2. 10 月收到签发方撤销，撤销 `effective_at=2026-08-01T00:00:00+08:00`。
3. 重新计算 8 月至今状态和下游投影。

**预期**：当前状态撤销；事件时间线按 8 月 1 日归位，同时展示 10 月入库；当前技能证据移除；冻结简历只允许追加后置警示。

## 7. 签发机构更名

1. 签发方 A 由“云图考试中心”更名为“云图认证院”。
2. 查看 C1、历史简历和事件链。

**预期**：`issuer_id` 与 C1 身份不变；当前页显示新名称及原名；历史冻结简历保留旧名称；时间线包含 `issuer.renamed`。

## 8. 验证链接失效

1. 来源 URL 曾核对一致。
2. 定时检查收到 404，后续又出现 TLS 超时。

**预期**：证据状态为 `link_broken/source_stale`，显示最后成功核对与最近失败；证书不自动撤销；文案说明“链接失效不代表被撤销”。

## 9. 链接可访问但内容不匹配

1. URL 返回 200。
2. 页面中编号或主体不一致。

**预期**：只能记录 `reachable_unverified` 或 `mismatch`，不得标记“已核对来源”或“权威认证”；匹配字段和不匹配字段都落库。

## 10. 上海时区午夜到期

证书 C4：`expires_at=2026-10-07T00:00:00+08:00`。

- 权威时间 `2026-10-06T23:59:59+08:00`：有效。
- 权威时间 `2026-10-07T00:00:00+08:00`：过期。
- UTC 浏览器在等价时刻渲染也必须显示同一结果。

**预期**：使用签发方时区转换的精确 instant；公开页显示 `Asia/Shanghai`，不使用服务器本地午夜猜测。

## 11. 日期型有效期语义

输入仅为“2027-03-15”，签发方规定到期日当天有效。

**预期**：后台要求时区和口径，并持久化 `2027-03-15 23:59:59 Asia/Shanghai`；没有时区或口径时返回 400。

## 12. 服务器时钟校正

1. 调度器依据快了 90 秒的本地时钟提前触发过期任务。
2. NTP 校时后写入时钟修正记录。

**预期**：提前触发不产生错误业务事实；重复任务幂等；临界读模型重建；修正记录可审计；原有 `recorded_at` 不被重写。

## 13. 下游传播与冻结简历

1. C1 当前被技能 S 和草稿简历 R 使用。
2. C1 撤销。
3. R 已冻结，另有一份新草稿 R2。

**预期**：S 当前证据移除 C1；R 快照 JSON 不变，可增加撤销警示；R2 候选不再包含 C1。

## 14. 公开墙文案与排序

打开访客墙并检查每张卡片。

**预期**：

- 状态分别展示有效期、来源、图片，不合并成“真/假”。
- 自报、已核对来源、链接失效、过期、撤销均有明确文案和时间。
- 折叠区能看到新获奖、补发、续期、更名、撤销等事件。
- 排序仅按最近事件、到期时间或标题；没有星级、权威分、含金量评分或同类隐含排序。
